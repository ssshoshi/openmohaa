// The game's lamps: where their bulbs are, and the light they give.
//
// The renderer's live lights (r_realtimeLighting, tr_rtlight.c) come from the
// bulbs here: the map's lights near a lamp give it their light, and a lamp
// the map gave no light of its own gets the one below. Made with
// tools/lamps/lamps.py (suggest finds bulbs from the mesh, sheet draws them).
//
//     <model>
//     {
//         kind shaded        // bulb, shaded (in a shade or globe), candle, lantern
//                            // (a flame: it flickers), or off (a lamp that is not lit)
//         color 1 0.86 0.68  // its light's colour, where the map gave it none
//         intensity 120      // as a map light's "light" key, where the map gave it none
//         bulb x y z         // one a bulb, in the model's frame as drawn
//                            // (its TIKI scale, not the map's)
//         glass 1 0.93 0.7   // its glass's colour, remodelled (tools/lamps/remodel.py): the
//                            // texture made for it (tools/lamps/glass.py) in place of the frame's
//         shade 0 0 1 0.8    // the way its shade closes it off, in its frame, and
//                            // how much of its light it stops that way (a bell
//                            // shade: the ceiling over it takes a fifth)
//         spot x y z 60      // a lamp that shines one way: that way in its
//                            // frame, and the cone's whole angle
//     }
